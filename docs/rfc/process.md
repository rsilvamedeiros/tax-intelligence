# Processo de RFC

RFC para mudança que afete contrato, isolamento, provedor externo ou distribuição de processos. Pequena refatoração interna não exige RFC. Documento deve incluir problema observável, opções, decisão proposta, impactos em dados/segurança, plano de migração, teste, rollback e responsáveis.

Estados: proposta → em revisão → aceita/rejeitada → substituída. ADR registra decisão arquitetural após avaliação; RFC pode permanecer rejeitada como evidência. Aceitação documental não autoriza deploy nem etapa de negócio. A [RFC 0001](0001-identity-membership-isolation.md) prepara identity provider, ciclo de membership e RLS da primeira vertical; status de proposta, implementação pendente.
