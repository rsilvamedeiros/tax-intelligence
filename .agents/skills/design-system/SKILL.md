# Objetivo e uso

Evoluir tokens e componentes UI reutilizados com acessibilidade e API pequena.

Consulte [AGENTS](../../../AGENTS.md) para invariantes e autorização; leia [docs/architecture/frontend.md](../../../docs/architecture/frontend.md) ao executar esta tarefa.

## Entradas

Uso real em telas, tokens existentes e comportamento.

## Instruções

Promova componente só após necessidade concreta. Preserve HTML semântico, contraste e foco; teste interação acessível antes de ampliar variantes.

## Checklist

Sem regra fiscal; sem props redundantes; responsividade e estados.

## Saída

Componente/token mínimo, uso real e evidência acessível.
