# Objetivo e uso

Implementar jornadas React Next.js acessíveis a partir de contratos aprovados.

Consulte [AGENTS](../../../AGENTS.md) para invariantes e autorização; leia [docs/architecture/frontend.md](../../../docs/architecture/frontend.md) ao executar esta tarefa.

## Entradas

Jornada, contrato e estados de interação.

## Instruções

Mantenha regra de negócio na API. Use servidor por padrão e cliente onde há estado. Valide transporte e represente loading, vazio, erro, recuperação e cancelamento.

## Checklist

Sem import de database; teclado; foco; falha e recuperação.

## Saída

Componentes e testes RTL/E2E relevantes.
